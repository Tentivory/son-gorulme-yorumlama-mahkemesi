# Son Görülme Yorumlama Mahkemesi

Resmi olmayan, fiilen de olmayan, buna rağmen kararı kesindir.

Bu kurum, bir kişinin “son görülme” saatinin ne anlama geldiğini bilimsel, hukuki ve tamamen gereksiz biçimde açıklar. Mahkeme, mesajın okunup okunmadığını bilmez. Bilmemesi kararın gücünü artırır. Delil yoktur. İçtihat vardır. İçtihat, delilden daha inatçıdır.

## Ne işe yarar

Birisi 14 dakika önce çevrimiçi görünmüştür. Sen mesaj atmışsındır. Cevap yoktur. Bu boşluk, evrende birçok şeyden daha gürültülüdür. Mahkeme o gürültüyü tutanağa çevirir.

## Kurulum

Python 3 yeter. Bağımlılık yoktur. Mahkemenin bütçesi de yoktur.

```bash
python3 mahkeme.py --kisi "Ayşe" --dakika 14
python3 mahkeme.py --kisi "müdür" --dakika 3 --online
python3 mahkeme.py --demo
```

## Daireler

| Daire | Yetki |
| --- | --- |

| 3. Daire | 12–59 dakika: gördü, düşündü, vazgeçti |
| 4. Daire | 60+ dakika: kişi başka bir ülkede değil, başka bir ruh halindedir |
| Çevrimiçi Daire | Yeşil nokta, masumiyet karinesi değildir |
